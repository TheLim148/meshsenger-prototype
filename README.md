# Bluetooth Mesh Chat Prototype

Черновой прототип Bluetooth mesh-мессенджера, разрабатываемый в рамках хакатона.

## О проекте

Проект представляет собой экспериментальную реализацию мессенджера, в котором устройства могут обмениваться сообщениями без использования интернета и центрального сервера.

Основная идея проекта — проверить возможность передачи сообщений между устройствами через Bluetooth с использованием принципов mesh-сети.

## Статус проекта

Данный репозиторий является прототипом.

Проект создаётся в сжатые сроки для хакатона и используется как черновая версия для проверки идеи, архитектуры и минимального сценария работы.

Часть кода и проектных решений создаётся с использованием нейросетевых инструментов. Финальная версия проекта для дипломной работы и дальнейшей разработки планируется в отдельном репозитории и будет переработана с нуля или существенно изменена.

## Архитектура

Репозиторий разделён на две основные части:

```text
android-app/  — Android-приложение на Kotlin
rust/         — Rust-ядро mesh-логики
docs/         — документация проекта
```

Android-приложение отвечает за:

- пользовательский интерфейс;
- работу с Bluetooth;
- поиск устройств;
- отправку и получение байтов.

Rust-ядро отвечает за:

- структуру сообщений;
- обработку входящих сообщений;
- TTL;
- защиту от дубликатов;
- store-and-forward;
- базовую mesh-логику.

## MVP

Минимальный сценарий проекта:

```text
Устройство A отправляет сообщение устройству C.
A напрямую не видит C.
A видит устройство B.
B получает сообщение от A и пересылает его C.
C получает сообщение от B.
```

## Ограничения прототипа

В текущей версии могут отсутствовать:

- полноценное шифрование;
- стабильная доставка сообщений;
- передача изображений и видео;
- защита от вредоносных узлов;
- полноценная маршрутизация;
- стабильная работа в фоне.
