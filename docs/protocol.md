# Протокол mesh-сети

## 1. Назначение

Данный документ описывает внутренний протокол взаимодействия между Android-приложением и Rust-ядром.

Android отвечает за Bluetooth, пользовательский интерфейс и передачу байтов.

Rust отвечает за обработку сообщений, mesh-логику, TTL, защиту от дубликатов и store-and-forward.

---

## 2. Версия протокола

Текущая версия: `0.1.0`

---

## 3. Узел

Каждое устройство имеет уникальный идентификатор.

Пример:

```text
node_a
node_b
node_c
```

---

## 4. Типы сообщений

В версии v1 поддерживаются:

- личные текстовые сообщения;
- широковещательные текстовые сообщения.

Запланировано:

- изображения;
- файлы;
- шифрование.

---

## 5. Формат сообщения

Сообщения передаются в формате JSON.

```json
{
  "protocol_version": "0.1.0",
  "message_id": "uuid",
  "message_type": "text",
  "chat_type": "private",
  "from": "node_a",
  "to": "node_c",
  "ttl": 5,
  "timestamp": 1710000000,
  "payload": {
    "text": "Привет"
  }
}
```

---

## 6. Типы чатов

Возможны два режима:

- `private` — сообщение конкретному получателю;
- `broadcast` — сообщение всем доступным узлам.

Для `broadcast` поле `to` принимает значение `null`.

```json
{
  "to": null
}
```

---

## 7. TTL

TTL ограничивает количество пересылок сообщения.

Правила:

- если `ttl <= 0`, сообщение не пересылается;
- при каждой пересылке значение `ttl` уменьшается на `1`.

---

## 8. Обработка дубликатов

Каждый узел хранит список уже полученных `message_id`.

Правила:

- если `message_id` уже есть в списке, сообщение игнорируется;
- если сообщение новое, оно сохраняется, обрабатывается и может быть переслано дальше.

---

## 9. Store-and-forward

Если получатель недоступен, сообщение сохраняется локально.

Когда получатель становится доступен, сообщение может быть отправлено повторно.

---

## 10. Взаимодействие Android → Rust

Android передаёт в Rust:

- полученные байты сообщения;
- идентификатор отправителя `peer_id`.

Rust принимает решение:

- показать сообщение пользователю;
- сохранить сообщение;
- переслать сообщение;
- проигнорировать сообщение.

---

## 11. Ответ Rust → Android

Rust возвращает список действий:

- `ShowMessage` — показать сообщение пользователю;
- `ForwardMessage` — переслать сообщение другим узлам;
- `SaveMessage` — сохранить сообщение;
- `DropMessage` — проигнорировать сообщение.

---

## 12. Ограничения версии v1

В первой версии отсутствуют:

- полноценное шифрование;
- передача изображений и видео;
- гарантия доставки;
- аутентификация пользователей;
- защита от вредоносных узлов.
